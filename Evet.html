☁️ Sunucu kurulumu

Şu anda hesap kapalı: uygulama yalnızca bu telefonda çalışıyor. Hesabı açmak için aşağıdaki adımları izleyin.

Kurulum adımları (Firebase, ücretsiz)
  1. console.firebase.google.com adresinde yeni proje oluşturun (Analytics gerekmez).
  2. Build > Authentication > Sign-in method: E-posta/Şifre yöntemini açın.
  3. Build > Realtime Database > Veritabanı oluştur (konum: europe-west1, kilitli mod).
  4. Database > Kurallar sekmesine aşağıdaki kuralları yapıştırıp Yayınla deyin.
  5. Proje ayarları > Genel: Web uygulaması ekleyin; apiKey değerini kopyalayın. Database sayfasındaki adresi (databaseURL) kopyalayın.
  6. İkisini yukarıya yapıştırıp Kaydedin; giriş ekranında "İlk kurulum" ile sahip hesabını oluşturun.

👥 Müşteri Kaydı
